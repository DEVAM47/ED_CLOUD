About this course

Almost every application, website, and service you use is backed by a database, and MySQL is one of the most widely used database systems in the world. This course teaches you how to design tables, write SQL queries, and manage real data the way professional developers do.

No prior experience is needed. Every lesson is hands-on: you'll write and run real queries alongside the instructor and finish with a portfolio of five real projects, including a fully designed e-commerce database and a student management system.

What you'll learn

✓ Relational database design and normalization
✓ Creating tables, keys, and constraints
✓ Writing SELECT queries with filtering and sorting
✓ Joins across multiple tables
✓ Aggregate functions and GROUP BY
✓ Subqueries and views
✓ Indexing and query performance basics
✓ Five portfolio-ready projects
