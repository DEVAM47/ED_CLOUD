About this course

HTML & CSS is where every web developer starts. This course walks you through building real web pages step by step, starting with plain HTML structure and moving into modern, responsive CSS layouts using Flexbox and Grid.

No prior experience is needed. Every lesson is hands-on: you'll write code alongside the instructor and finish with a portfolio of five real projects, including the landing page you're looking at right now.

What you'll learn

✓ Semantic HTML structure and accessibility basics
✓ CSS selectors, box model, and specificity
✓ Flexbox and Grid for real layouts
✓ Responsive design with media queries
✓ Forms, tables, and navigation menus
✓ Animations, transitions, and hover effects
✓ Deploying a finished site online
✓ Five portfolio-ready projects
