About this course

Artificial intelligence now powers search engines, recommendation systems, chatbots, and countless everyday tools. This course breaks down how AI actually works, without assuming any prior background in math or programming.

You'll build intuition first, then get hands-on with real, guided examples: training a simple machine learning model, building a small neural network, and experimenting with a language model. You'll finish with a clear mental model of what AI can and can't do, and a foundation strong enough to keep learning in any specialization you choose next.

What you'll learn

✓ Core concepts: AI, machine learning, and deep learning
✓ How models learn from data
✓ Supervised, unsupervised, and reinforcement learning
✓ Neural networks and how they're trained
✓ Natural language processing basics
✓ Computer vision fundamentals
✓ Responsible AI, bias, and limitations
✓ Three hands-on guided projects
